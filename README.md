# Sueño Dull Home

Sitio responsive en HTML, CSS y JavaScript puro, sin dependencias de compilación. Abrir `index.html` en el navegador o servir la carpeta raíz del proyecto con un servidor estático.

Incluye las seis imágenes proporcionadas, filtros de colección, galería ampliable con cierre por Escape, menú móvil y selección por ambiente. Incluye enlaces directos a WhatsApp (+595 995 603 795) e Instagram (@suenodull.home). No incluye precios inventados. El selector muestra la colección elegida; no envía solicitudes ni pedidos.

Los archivos editables son `index.html`, `styles.css` y `app.js`. Las fuentes de Google Fonts tienen alternativas locales si no hay conexión.


## Materiales y asesoramiento
Fondo #F4EEE4, acceso flotante a WhatsApp, guía educativa de componentes y tapizados, selector de confort, proceso de seis etapas y configurador de presupuesto. El formulario de citas abre WhatsApp con una fecha y franja preferidas, sujeto a confirmación; no reserva automáticamente. Referencia incorporada: Sueno_Dull_Home_Catalogo_Materiales.pptx, con imágenes identificadas como ilustrativas. Opciones y combinaciones sujetas a confirmación por pedido. Los esquemas son ilustraciones, no fotografías de taller. Para completar macros individuales de las siete familias, usar fotografías de las muestras reales.

## Publicar en GitHub Pages

Subí el contenido de esta carpeta al repositorio, con `index.html` directamente en la raíz, junto a los archivos CSS, JavaScript y la carpeta `assets`. No subas solamente el ZIP ni una carpeta contenedora.

En el repositorio, abrí Settings → Pages, elegí Deploy from a branch, seleccioná la rama donde subiste los archivos y la carpeta / (root), y guardá.
